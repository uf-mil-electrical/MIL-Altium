# Getting Started
When getting started with the MIL Electrical Team please go through the following steps...

1) Go through the EE Git Setup.docx file under the [GitHub Tutorial](https://github.com/uf-mil-electrical/Getting-Started/tree/master/GitHub_Tutorial) folder and make sure that your github environment is setup properly
   on your PC.

2) Go through the Altium Training documents under the Altium Tutorial folder to learn how to design PCBs.
   You can find the link to the repo here: https://github.com/uf-mil-electrical/Training_Altium
      - [Here](https://www.youtube.com/playlist?list=PLuj9nz7PiCZD4_rxCJMWIFjxp5TgkOI0M) is a great playlist by [Michael Stapleton](https://www.youtube.com/@michaelstapleton5276) if you'd like a video tutorial.

3) If you are a new member (or have yet not done so) please complete the [Altium Assignment](https://github.com/uf-mil-electrical/Getting-Started/tree/master/Altium%20Assignment) within the first 2 - 3 weeks of your first semester.

4) Go through the Firmware/CCS Training documents to learn how to design firmware at MIL.
   You can find the link to the repo here: https://github.com/uf-mil-electrical/Training_Firmware

NOTE: Steps 2-3 and 4 can be done interchangeably depending on what your task is.
